# Leading ห (ห นำ) audio recordings

Add one MP3 recording for each leading ห combination in this folder. The listen button in the practice page automatically uses the matching file. Until a recording is added, it falls back to the device's Thai text-to-speech voice.

## Recording checklist

- Read only the Thai phrase shown below.
- Export each clip as an `.mp3` using the exact filename.
- Record clearly at a natural learning pace, with no long silence or background music.
- Example for `01.mp3`: say **หอ นำ งอ งู**.

Use these exact filenames:

```text
01.mp3  หอ นำ งอ งู
02.mp3  หอ นำ นอ หนู
03.mp3  หอ นำ ณอ เณร
04.mp3  หอ นำ มอ ม้า
05.mp3  หอ นำ ยอ ยักษ์
06.mp3  หอ นำ ญอ หญิง
07.mp3  หอ นำ รอ เรือ
08.mp3  หอ นำ ลอ ลิง
09.mp3  หอ นำ ฬอ จุฬา
10.mp3  หอ นำ วอ แหวน
```
