# Special ร combination audio recordings

Add one MP3 recording for each special ร combination in this folder. The practice page uses the matching file when a learner taps the listen button. Until a recording is added, it falls back to the device's Thai text-to-speech voice.

## Recording checklist

- Read only the Thai example word below, clearly and at a natural learning pace.
- Export each clip as an `.mp3` using the exact filename.
- Do not include the filename, English translation, long silence, or background music.
- Example for `01.mp3`: say **สร้าง**.

Use these exact filenames:

```text
01.mp3  สร้าง  (สร — to build)
02.mp3  ศรี    (ศร — glory / honour)
03.mp3  จริง   (จร — true / really)
04.mp3  ไซร้   (ซร — indeed, poetic)
05.mp3  ทราบ  (ทร — to know)
```
