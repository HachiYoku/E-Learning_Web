# Leading อ (อ นำ) audio recordings

Add one MP3 recording for each of the four standard leading อ words in this folder. The listen button on the practice page automatically uses the matching file. Until a recording is added, it falls back to the device's Thai text-to-speech voice.

## Recording checklist

- Read only the Thai word shown below, clearly and at a natural learning pace.
- Export each clip as an `.mp3` using the exact filename.
- Do not include English translations, filenames, long silence, or background music.
- Example for `01.mp3`: say **อย่า**.

Use these exact filenames:

```text
01.mp3  อย่า    (do not / don't)
02.mp3  อยาก    (to want)
03.mp3  อย่าง   (kind / type)
04.mp3  อยู่    (to stay / be located)
```
