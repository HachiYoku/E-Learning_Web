# True consonant cluster audio recordings

Add one MP3 recording for each true consonant cluster in this folder. The practice page uses the matching file when a learner taps the listen button. Until a recording is added, it falls back to the device's Thai text-to-speech voice.

## Recording checklist

- Read the example word shown below, clearly and at a natural learning pace.
- Export each clip as an `.mp3` using the exact filename.
- Do not include the filename, English translation, long silence, or background music.
- Example for `01.mp3`: say **กราบ**.

Use these exact filenames:

```text
01.mp3  กราบ       (กร)
02.mp3  ขรุขระ     (ขร)
03.mp3  ครู        (คร)
04.mp3  ตรง        (ตร)
05.mp3  ปรับ       (ปร)
06.mp3  พระ        (พร)

07.mp3  กลัว       (กล)
08.mp3  ขลาด      (ขล)
09.mp3  คลาย      (คล)
10.mp3  ปลา       (ปล)
11.mp3  ผลไม้      (ผล)
12.mp3  พลอย      (พล)

13.mp3  กวาง      (กว)
14.mp3  ขวาน      (ขว)
15.mp3  ควาย      (คว)
```
